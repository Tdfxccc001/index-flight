# 行情来源、处理与使用范围

## 身份与实际覆盖

- 指数为上证综合指数，000001.SH；请求使用 **sh000001**，不使用 sz000001（平安银行）。身份参照[上交所上证系列指数列表](https://www.sse.com.cn/market/sseindex/indexlist/index.shtml?classid=010202)以及[新浪指数页面](https://finance.sina.com.cn/realstock/company/sh000001/nc.shtml)，后者明确标注“上证综合指数(000001.SH)”。
- 版本抓取日为 2026-10-21（上海时区，收盘后）；正式数据 2022-01-04 至 2026-10-21，共 1,160 条。额外 2021-12-31 收盘 3639.78，2022-01-04 收盘 3632.33，首日变化 -7.45。
- 主源：腾讯财经公开日 K `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get`，逐年请求，字段为日期/开盘/收盘/最高/最低/成交量。本指数为原始点数，未对指数进行股票复权处理。
- 独立核验：新浪财经日 K `https://money.finance.sina.com.cn/quotes_service/api/json_v2.php/CN_MarketData.getKLineData`，symbol=sh000001, scale=240, datalen=2000。
- 原始 HTTP JSON 保留在 `data/raw/`；确切 URL、抓取时间、SHA-256、样本和数量见 `market_validation.json` 与静态 JSON 的 fetchedAt。

## 校验与加工

对两源的全部 1,160 日期集合比较，无差集；对收盘值逐条比较，容忍供应商显示精度差 0.021 点，本次无差异。由此检查相对独立源的缺失交易日，而不是把所有工作日误认为交易日。检查排序、重复日期（重复值不一致即失败）、有限值、合理点位范围、首日基准、周末、变化和方向。未用填充值、估算行情或随机行情补日。两个来源一致并不等价于逐日获得交易所原始认证，已保留原始响应供追溯。

每日 change=close-前一实际交易日close，保留两位小数；涨/跌/平映射 up/down/flat。收盘和点差都未用于负柱高。v0.2.0 高度参数固定于 balance.ts：Hmin=2.8、Hmax=11、Dcap=250、S=18，使用 GDD 对数单调压缩公式。比 v0.1.0（Hmin=1.5、S=22）抬高低幅变化对应的柱体；另对整个场景及飞机统一施加 1.5 倍竖直呈现变换，使高度更可辨。摄像机同步使用变换后的坐标；碰撞与可达搜索仍使用同一套原始逻辑坐标，没有仅拉伸柱子的碰撞错位。正式日期、收盘、涨跌及数据 SHA-256 未改动。

`python scripts/fetch_market.py` 可重复执行，按上海时区排除盘中当日，交叉校验通过后以临时文件原子替换正式静态 JSON。未完成核验时保留既有正式版本，不将不完整请求伪装为最新数据。将来新浪 2000 根不足以覆盖全部历史时，脚本会因日期集合不一致而失败，应分段核验或更换独立完整来源。

## 访问与授权的实际边界

本次为少量、无需 token 的公开 HTTPS 只读请求，没有登录、绕过访问控制或上传竞赛内容。第三方财经数据不因公开可读取就自动成为开放许可数据；本次未取得腾讯、新浪或交易所授予的商业再分发许可证。因此当前交付用于本地原型及核验，**不能将本项目数据描述为已获开放再分发授权**。公开部署或商业发行前应确认供应商及交易所相关数据权利，或替换成明确许可相应用途的日线源。未将游戏发布到第三方平台。

竞赛扫描报告仅保存在本项目，原始竞赛目录全程只读。采集脚本不会引用、上传该目录。
